Concept 02 / Depth as interface

SpatialInterface

Um experimento sobre como profundidade, perspectiva e resposta ao ponteiro podem criar presença sem WebGL. O foco aqui é transformar CSS 3D em linguagem de interface, não em efeito decorativo.

CSS 3DPerspectivePointer EventsVanilla JS
mova o ponteiro / incline a cena
Como foi pensado

Profundidade com função.

O objeto central reage ao usuário, mas mantém hierarquia visual, legibilidade e baixo custo de execução. A ideia é mostrar raciocínio de interface: resposta, foco, contenção e continuidade.

01 / Input

Movimento

O ponteiro altera rotação nos eixos X e Y com resposta curta e previsível.

02 / Space

Perspectiva

Faces CSS formam um volume real no espaço 3D do navegador, sem biblioteca externa.

03 / Restraint

Controle

O efeito fica concentrado no hero para não competir com o conteúdo e nem degradar a leitura.
